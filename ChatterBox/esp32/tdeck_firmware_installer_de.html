T-Deck Type
Ist das Gerät nicht aufgeführt, kann die Option „Alle anderen“ ausgewählt werden; eine Kompatibilität kann jedoch nicht garantiert werden.

  1. Empfohlen - SD-Karten werden dringend empfohlen, sind jedoch nicht erforderlich. Es können nur kompatible SD-Karten verwendet werden.
  2. Das T-Deck wird über ein hochwertiges Datenkabel mit dem PC verbunden.
  3. Das T-Deck wird eingeschaltet.
  4. Die Trackball-Taste (linke/erste Taste) wird gedrückt gehalten, anschließend wird die Reset-Taste (seitlich) betätigt; danach wird die Trackball-Taste losgelassen.
  5. Unten wird auf die Schaltfläche „Installieren“ geklickt; anschließend wird den Anweisungen gefolgt.
  6. In einigen Fällen kann es erforderlich sein, die Trackball-Taste während der Installation gedrückt zu halten.
